## Review rules

Recurring expectations from this repository's code review history, found by [difflore](https://github.com/difflore/difflore-cli) in 300 maintainer comments across 142 pull requests. Each rule links to the reviews it came from.

- **Commit the failing test with its buggy snapshot first, then the fix.** The fix commit's snapshot diff then demonstrates the behaviour change. ([#17545](https://github.com/rust-lang/cargo/pull/17545#discussion_r4154892995), [#17531](https://github.com/rust-lang/cargo/pull/17531#discussion_r4128016761), [#17517](https://github.com/rust-lang/cargo/pull/17517#discussion_r4107703370))
- **Split refactorings and unrelated changes into separate atomic commits.** Cargo merges preserve individual commits; reviewers request C-SPLIT extractions. ([#17296](https://github.com/rust-lang/cargo/pull/17296#discussion_r3695853827), [#17269](https://github.com/rust-lang/cargo/pull/17269#discussion_r3669413226), [#16807](https://github.com/rust-lang/cargo/pull/16807#discussion_r3523355786))
- **Use snapbox wildcards like `[..]` for volatile or irrelevant snapshot output.** Exact expectations break when rustc flags or values change. Applies to `tests/**`. ([#17518](https://github.com/rust-lang/cargo/pull/17518#discussion_r4111791774), [#17517](https://github.com/rust-lang/cargo/pull/17517#discussion_r4108330820), [#17298](https://github.com/rust-lang/cargo/pull/17298#discussion_r3846847410))
- **Check git CLI flags against Cargo's minimum supported Git version before use.** Newer flags silently raise MSGV and break older distro Gits. Applies to `src/sources/git/**`. ([#17422](https://github.com/rust-lang/cargo/pull/17422#discussion_r3906543386), [#17422](https://github.com/rust-lang/cargo/pull/17422#discussion_r3906391062), [#17400](https://github.com/rust-lang/cargo/pull/17400#discussion_r3877198388))
- **Format book callouts as mdBook admonitions like `> [!NOTE]` or `> [!WARNING]`.** The book renders mdBook alert syntax instead of plain 'Note:' paragraphs. Applies to `doc/book/**`. ([#17384](https://github.com/rust-lang/cargo/pull/17384#discussion_r3834957328), [#17384](https://github.com/rust-lang/cargo/pull/17384#discussion_r3834956591), [#17384](https://github.com/rust-lang/cargo/pull/17384#discussion_r3834953687))
- **Disclose LLM involvement; AI-authored PRs need pre-arranged reviewers and human-written communication.** Cargo adopted rust-lang/rust's LLM policy with Cargo-specific interpretations. ([#17517](https://github.com/rust-lang/cargo/pull/17517#discussion_r4115585962), [#17330](https://github.com/rust-lang/cargo/pull/17330#discussion_r3739574725), [#17330](https://github.com/rust-lang/cargo/pull/17330#discussion_r3739562435))
- **Keep per-session state on `GlobalContext`, not global statics or threaded parameters.** In-process tests share one process; globals leak across test contexts. Applies to `src/**`. ([#17513](https://github.com/rust-lang/cargo/pull/17513#discussion_r4099695231), [#17267](https://github.com/rust-lang/cargo/pull/17267#discussion_r3793613911))
- **Use `with_stderr_data` snapshot assertions instead of `*_contains` matching.** cargo-test-support prefers redacted snapshots over substring assertions. Applies to `tests/**`. ([#17220](https://github.com/rust-lang/cargo/pull/17220#discussion_r3590498155), [#17203](https://github.com/rust-lang/cargo/pull/17203#discussion_r3565109205))
- **Prefer `IndexMap`/`IndexSet` over `HashMap`/`HashSet`.** clippy.toml's disallowed_methods enforces deterministic iteration order. Applies to `**/*.rs`. ([#17180](https://github.com/rust-lang/cargo/pull/17180#discussion_r3526335161), [#17169](https://github.com/rust-lang/cargo/pull/17169#discussion_r3525326778))
- **Write `type(scope): summary` commits with lowercase Cargo-subcommand scopes like `fix(run)`.** Cargo convention scopes types to the uncapitalized subcommand name. ([#17513](https://github.com/rust-lang/cargo/pull/17513#discussion_r4098540700), [#17373](https://github.com/rust-lang/cargo/pull/17373#discussion_r3828476899))
- **Document unstable features in unstable.md; stable docs copy it at stabilization.** Stable documentation is ported verbatim from unstable.md. Applies to `doc/book/**`. ([#17517](https://github.com/rust-lang/cargo/pull/17517#discussion_r4107919198), [#15056](https://github.com/rust-lang/cargo/pull/15056#discussion_r3889403527))
- **Mirror config option changes in config.md and environment-variables.md's config table.** The env-var page duplicates config keys and gets forgotten. Applies to `doc/book/src/reference/**`. ([#17329](https://github.com/rust-lang/cargo/pull/17329#discussion_r3928079597), [#17335](https://github.com/rust-lang/cargo/pull/17335#discussion_r3745961951))
