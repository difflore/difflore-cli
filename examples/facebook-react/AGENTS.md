## Review rules

Recurring expectations from this repository's code review history, found by [difflore](https://github.com/difflore/difflore-cli) in 300 maintainer comments across 165 pull requests. Each rule links to the reviews it came from.

- **Test DevTools through real React roots and public APIs, not mocked internals.** Internal mocks repeat implementation and miss cross-version regressions. Applies to `packages/react-devtools-*/**`. ([#37137](https://github.com/react/react/pull/37137#discussion_r3666354658), [#37076](https://github.com/react/react/pull/37076#discussion_r3625051850), [#37048](https://github.com/react/react/pull/37048#discussion_r3625044461))
- **Use strict `!== null` checks for optional values unless weak equality is justified.** Reviewers require a specific reason for weak equality. ([#37457](https://github.com/react/react/pull/37457#discussion_r3895116168), [#37457](https://github.com/react/react/pull/37457#discussion_r3895111331), [#37457](https://github.com/react/react/pull/37457#discussion_r3895110217))
- **Derive or adjust DevTools view state during render or event handlers, never effects or refs.** Post-paint effects paint stale UI and thrash selection. Applies to `packages/react-devtools-shared/src/devtools/views/**`. ([#36944](https://github.com/react/react/pull/36944#discussion_r3674709918), [#36944](https://github.com/react/react/pull/36944#discussion_r3632068347), [#36828](https://github.com/react/react/pull/36828#discussion_r3451926149))
- **Use Flow chunk types to narrow `ReactFlightClient` handler state, not `any` or runtime checks.** Flow already encodes initialized versus blocked chunks. Applies to `packages/react-client/src/ReactFlightClient.js`. ([#37542](https://github.com/react/react/pull/37542#discussion_r3956537669), [#37542](https://github.com/react/react/pull/37542#discussion_r3956492768), [#37542](https://github.com/react/react/pull/37542#discussion_r3956476405))
- **Let impossible states throw in DevTools instead of silently guarding them.** Silent fallbacks hide real bugs and produce incorrect results. Applies to `packages/react-devtools-*/**`. ([#35929](https://github.com/react/react/pull/35929#discussion_r2867800362), [#35123](https://github.com/react/react/pull/35123#discussion_r2692224989), [#35123](https://github.com/react/react/pull/35123#discussion_r2691528193))
- **Create hot-path callbacks with `.bind` instead of per-call closures.** Avoids extra closure allocation in server and DOM hot paths. Applies to `packages/react-*/src/**`. ([#37457](https://github.com/react/react/pull/37457#discussion_r3893390607), [#37258](https://github.com/react/react/pull/37258#discussion_r3749490540), [#37053](https://github.com/react/react/pull/37053#discussion_r3610048346))
- **Add host-config methods instead of inspecting opaque Flight chunk or reference types.** Host configs own concrete chunk shapes and backpressure behavior. Applies to `packages/react-server/src/ReactFlightServer.js`. ([#36984](https://github.com/react/react/pull/36984#discussion_r3551339327), [#36516](https://github.com/react/react/pull/36516#discussion_r3310590848), [#36516](https://github.com/react/react/pull/36516#discussion_r3310493843))
- **Gate view-transition attributes and Offscreen behavior behind the matching ReactFeatureFlags flag.** Unflagged builds must keep existing rendering behavior. Applies to `packages/**`. ([#36917](https://github.com/react/react/pull/36917#discussion_r3511278174), [#36917](https://github.com/react/react/pull/36917#discussion_r3511253499), [#35945](https://github.com/react/react/pull/35945#discussion_r2875000335))
- **Keep hand-tuned loops in hot paths like ReactPerformanceTrackProperties unless measurements justify changes.** Hot paths need fine-tuned performance, not stylistic refactors. ([#35776](https://github.com/react/react/pull/35776#discussion_r2805917779), [#35128](https://github.com/react/react/pull/35128#discussion_r2536662699), [#35128](https://github.com/react/react/pull/35128#discussion_r2536655257))
- **Set new ReactFeatureFlags to `__EXPERIMENTAL__` before default enablement or removal.** OSS needs an enabled experimental state before cleanup. Applies to `packages/shared/ReactFeatureFlags.js`. ([#37290](https://github.com/react/react/pull/37290#discussion_r3784252070), [#37013](https://github.com/react/react/pull/37013#discussion_r3582119243))
- **Assert console output with `assertConsoleErrorDev` or `assertConsoleDev` between `act` calls.** Raw console mocks bypass the required assertion tracking. Applies to `packages/**/src/__tests__/**`. ([#36564](https://github.com/react/react/pull/36564#discussion_r3453971042), [#36802](https://github.com/react/react/pull/36802#discussion_r3428229590))
